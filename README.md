# Portfolio de Randy Raza

Site statique compatible avec GitHub Pages, sans installation ni compilation.

- `index.html` : textes, projets, liens et formulaire de contact.
- `styles.css` : couleurs, typographie et affichage mobile.
- `Images/` : photos, projets et CV (`Resume.pdf`).
- `fonts/` : polices Geist hébergées avec le site.
- `favicon.svg` : icône du site.

Pour voir le site en local, lancer `python3 -m http.server 8080` dans ce dossier, puis ouvrir http://localhost:8080.

Le formulaire utilise le compte Formspree déjà configuré sur le site précédent. Une soumission réelle est nécessaire pour confirmer la réception des messages.

Pour mettre à jour le site, modifier les fichiers puis pousser la branche configurée dans les paramètres GitHub Pages du dépôt.
